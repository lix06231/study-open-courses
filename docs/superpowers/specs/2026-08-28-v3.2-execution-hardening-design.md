# study-open-courses v3.2 Execution Hardening Design

Date: 2026-08-28
Status: Implemented; pending final independent review

## Goal

Make the Skill reliably executable on long, multimodal learning resources while creating a non-overridable rule that paid instructional content is never acquired or processed by the Agent.

## Scope

The upgrade remains one portable Agent Skill. It changes routing, source eligibility, acquisition, execution state, learning reconstruction QA, publishing QA, README guidance, and behavioral validation. It does not add a downloader, media model, renderer, account automation, or external publishing system.

## 1. Free-access processing gate

Classify every identifiable candidate before community validation or instructional-content access:

| Access class | Processing behavior |
|---|---|
| `free_access` | Real instructional content is reachable without payment, subscription, trial, credits, institutional entitlement, or a purchased account. It may proceed subject to platform, copyright, and authorization rules. A free account login is allowed when no paid entitlement is involved. |
| `paid_or_entitlement_gated` | Public metadata only. Never open gated lessons or use a paid authenticated session. Never download, capture, record, ASR, OCR, extract, translate, or reconstruct the gated content. |
| `public_excerpt` | Process only the excerpt's actual public coverage. Never infer the paid remainder or call the excerpt complete. |
| `official_free_edition` | Treat as a separate source with its own version, scope, completeness, validation, and provenance. |
| `unknown` | Do not ingest. Resolve access status or continue discovery. |

This is a Skill policy, not a legal-rights estimate. User purchase, explicit authorization, lack of DRM, a logged-in browser, a deadline, or personal-use intent cannot override it.

For goal-only tasks, paid resources are excluded from the processing-primary candidate set. An especially suitable paid resource may appear in a clearly separate “paid option for manual study” note based only on public metadata. The Agent states that payment is required, does not imply it inspected gated content, and continues searching for free-access alternatives.

For a user-named paid resource, the Agent assesses only public metadata and community evidence, explains the processing boundary, suggests studying the original manually if the learner chooses to purchase it, and offers free-access alternatives. User-authored notes, reflections, and short excerpts may be used for tutoring, but they do not authorize bulk course reconstruction or requests for paid-course exports.

## 2. Explicit routes and confirmation boundaries

- A named resource records Discovery and candidate Ranking as `not applicable`; validation and fit remain descriptive rather than rejection gates.
- A goal-only route performs discovery, access classification, community validation, then learner-fit ranking.
- Before the learner confirms a Moderate free-access fallback, the Agent may inspect public metadata and a representative public sample needed for assessment. It may not bulk-acquire or reconstruct the resource.
- “Reasonable search” must record discovery routes, evidence sources, candidates rejected, and why continued search is unlikely to change the decision.

## 3. Durable execution state and honest completion

Add `references/execution-state.md` with:

- artifact levels: metadata index, source coverage map, curriculum map, reconstructed learning artifact;
- five separate totals: expected, acquired, processed, verified, reconstructed;
- `X/Y` rollups and per-item status, attempts, last error, blocking impact, and next action;
- resume-first behavior and checkpoints after acquisition, integrity, reconstruction, and publishing;
- batch failure isolation and deadline-driven scope freezing;
- a rule that “complete” may modify only the named artifact level.

Global integrity must pass before finalization. Batches may produce provisional reconstruction, clearly marked as provisional and revisable when later dependencies are discovered.

## 4. Multimodal acquisition and verification

The acquisition reference will require a complete source set rather than one linear “best source.” Captions or ASR provide the speech channel; slides, code, diagrams, demonstrations, exercises, and attachments remain complementary requirements.

For video, detect visual references and inspect the corresponding frames, slides, code, diagrams, or demonstrations. Record `visual_coverage`; unresolved visual-only teaching content is blocking when it affects the outcome.

ASR verification must inspect each lesson's opening, middle, ending, every low-confidence or discontinuous segment, high-impact names, numbers, formulas, and code, plus duration/coverage mismatches. Processing coverage and verified coverage remain separate.

## 5. Translation verification

Record source and target language, preserve a bilingual glossary for important terms, retain original wording when translation is uncertain, verify names/numbers/formulas/code, and distinguish translation from new teaching synthesis. Translation uncertainty remains visible in the source map and final artifact.

## 6. Learning QA gate

Add `references/learning-quality.md` and require it after reconstruction and optional compression but before publishing. Verify:

- each promised outcome maps to instruction and practice;
- prerequisites and dependency order are coherent;
- source-derived explanations are accurate and traceable;
- new examples are labeled and technically correct;
- every exercise or understanding check has usable feedback or answer guidance;
- compression preserves transfer-critical reasoning and practice;
- study-time estimates state assumptions;
- gaps, uncertainty, and return-to-original steps are visible.

## 7. Publishing clarification

- Formal self-contained HTML means one file with required styles and permitted small assets embedded. A required sidecar asset means the artifact is an offline package, not self-contained HTML, and must be explicitly requested or reported as blocked.
- A non-empty but damaged PDF is a failed PDF. Fix source/rendering errors, try another available lawful renderer when practical, and never claim completion until visual verification passes.
- Curriculum maps and companions receive artifact-specific minimum schemas; they are not forced to masquerade as full reconstructed courses.

## 8. Validation

Behavioral GREEN scenarios must cover paid Strong versus free Moderate, user-named purchased course, public preview plus gated remainder, free-login course, official free edition, long-course resume, visual-only video content, ASR verification, translation uncertainty, Moderate confirmation, deadline scope freeze, Learning QA failure, self-contained HTML, and damaged PDF.

Structural checks include bundled Skill validation, relative links, placeholders, UTF-8, Git diff, installed-copy parity when synchronization is later authorized, and independent final review.

## Authorization boundary

This work may create local commits. It does not authorize push, pull request, merge, remote publication, or synchronization into installed Skill directories without a separately recorded decision.
