# v3.2.1 delivery-intent validation

Date: 2026-08-28

This focused regression check covers the ambiguity observed in Kilo's delivery. It checks mandatory decisions in the final instructions; it is not presented as an independent cross-model blind test.

| User request or state | Required decision | Result |
|---|---|---|
| “帮我写一份课程” | Lock `requested_artifact_level: reconstructed learning artifact`; do not reinterpret it as a preview, outline, curriculum map, or course plan. | PASS |
| “把这些资料整理成课程” without naming formats | Lock `delivery_contract: three_primary_files`. | PASS |
| Formal course produces many lesson Markdown files | They are optional extras and do not replace one complete canonical `.md`. | PASS |
| Formal course produces a multi-page HTML folder | It is an optional site/offline package and does not replace one complete self-contained `.html`. | PASS |
| Formal course produces chapter PDFs | They are optional extras and do not replace one complete `.pdf`. | PASS |
| Renderer or source blocker prevents a required file | Report partial completion and the missing primary file; do not downgrade or claim the course complete. | PASS |
| User explicitly asks only for an outline or only Markdown | Honor that explicit lower artifact level or format override. | PASS |
| Work resumes under another Agent | Preserve requested artifact level and delivery contract unless the user explicitly changes them. | PASS |

Mechanical validation must also confirm that `SKILL.md`, `references/publishing.md`, and `references/execution-state.md` contain the same intent and delivery contract.
