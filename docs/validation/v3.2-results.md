# v3.2 validation results

Date: 2026-08-28

## Scope and method

This record validates the repository form of `study-open-courses` v3.2. The paid-resource RED baseline is preserved in [paid-resource-baseline.md](paid-resource-baseline.md). GREEN checks below are decision-table tests against the final runtime instructions, followed by mechanical structure and repository checks. They establish that the written Skill has an explicit route for each case; they do not claim that every possible host or model has been behavior-tested.

For each scenario, the reviewer located the governing instruction and checked that the expected decision is mandatory rather than merely suggested. A fresh independent whole-branch review remains part of release review.

## Cross-file consistency checks

- Access classes and eligibility values agree between `SKILL.md` and `references/source-acquisition.md`.
- Source-manifest fields cover the execution ledger's access, status, attempt, error, visual, reconstruction, blocking, and next-action state.
- All four exact completion names require a matching `learning_qa: pass` in both `SKILL.md` and `references/execution-state.md`.
- `references/learning-quality.md` defines a minimum schema/profile for metadata index, source coverage map, curriculum map, companion, and reconstructed course.
- `references/publishing.md` requires literal one-file HTML and treats material PDF rendering defects as failure.
