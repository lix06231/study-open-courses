# Stable project context

`study-open-courses` is a learner-first Agent Skill for selecting trustworthy learning resources and rebuilding lawfully accessible instructional material into usable learning artifacts.

## Stable product rules

- Community validation admits proactively recommended primary resources; learner fit ranks admitted resources.
- The artifact is for a human learner, not model-memory ingestion or generic summarization.
- Integrity precedes reconstruction; reconstruction precedes optional compression.
- Formal complete delivery defaults to equivalent Markdown, self-contained HTML, and PDF unless the user explicitly requests formats.
- Publishing files never implies external upload or remote mutation authorization.
- Paid instructional content is never an Agent acquisition or processing source. It may be mentioned as a manual-study option from public metadata, with its payment requirement disclosed, while the Agent continues to find free-access alternatives.

## Current version goal

Version 4.1 makes the course-pack path deterministic: initialized machine-readable state, item-derived coverage totals, verifiable source locators, artifact-revision and hash binding, canonical Markdown, offline standalone HTML, printable answers, path containment, and regression-tested completion validation.
